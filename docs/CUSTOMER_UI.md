# 客户原版界面与修改范围

客户界面直接取自 `Project_T/ProjectCarbonCal/src`，副本位于 `web/src/customer`。原项目未改动。八个业务页面、录入组件及计算数据沿用客户源码；后续依据用户确认重排展示结构，不使用原平台的录入页面重建。

依据用户及《修改.docx》，已落实以下基础要求：

1. 服务器存盘：原操作连接项目 API，项目信息、模型图片和四类明细写入数据库，按登录用户与项目隔离。原空白新增行在有效填写后保存；未完成保存时提供离开保护。
2. 登录：账号登录后进入项目，名称统一为“碳建智算平台”，登录页标题居中。登录过期时保留工作区草稿，同账号重新登录后可继续保存。
3. 字体：通过 `styles/typography.css` 调整字体、字号与文字对比度；保留 `styles/base.css` 原样。
4. 网站链接：按用户标注放在建材搜索框右侧、分类按钮左侧，文字仅为“指导价格”，新窗口打开 `https://www.zjzj.net/`；材料清单右上角原价格来源及季度内容已删除。

`customer.html` 是独立文档，避免平台全局 CSS 影响客户界面。默认项目入口加载此文档；已有因子和版本工具位于项目菜单的独立入口。

## 后续授权的功能与视觉优化

用户在验收后明确否定过度玻璃化的展示，最终选择“浅色专业工作台：白底、清晰表格、克制的蓝色”。当前以白色内容区、浅灰工作区和蓝色操作按钮为统一视觉，不再使用大面积渐变、模糊、装饰建筑与重复卡片。客户覆盖样式位于 `web/src/customer/styles/workspace.css`；平台样式位于 `web/src/styles/platform-workspace.css`。登录名称放大至48px，与表单整体居中，手机端缩放。

项目目录使用表格；首页先显示当前项目与排放总览，再展示分阶段明细，只有真实上传图片才显示图片区域。统计数字合并为汇总行，筛选紧邻录入表格。页面标题、导航与操作文案一致，状态由真实数据决定。使用 impeccable 的简化与润色检查收尾；设计约束见根目录 `DESIGN.md`。

- 工作区补充返回项目目录、加载失败重试、保存中离开保护；空白行保持本地草稿，有效内容写入服务器。
- 修复连续编辑与新增过程中的竞态，导出前等待保存，避免导出旧数据。
- 回收量按真实单位分组，避免吨、平方米、立方米混加；缺少分母时显示“—”。
- 单位面积建材成本与服务器口径一致；核算范围、成本占比分母和减碳指标使用准确名称。
- 图表坐标、正负值比例及图例对应修正；小额非零数据保留可见精度。
- 桌面保留客户业务录入流程，窄屏表格在自身容器内横向滚动；支持减少动态效果的系统设置。

本地数据库持久化与 GitHub 代码推送不等于部署到甲方服务器。生产安装与数据库配置参见 `DEPLOYMENT.md`。
