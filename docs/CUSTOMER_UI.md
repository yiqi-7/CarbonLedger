# 客户原版界面与修改范围

客户界面直接取自 `Project_T/ProjectCarbonCal/src`，副本位于 `web/src/customer`。原项目未改动。八个页面的模板结构、组件、图表和基础样式沿用客户源码，不使用原平台的录入页面重建。

依据用户及《修改.docx》，本次仅落实：

1. 服务器存盘：原操作连接项目 API，项目信息、模型图片和四类明细写入数据库，按登录用户与项目隔离。原空白新增行在有效填写后保存；未完成保存时提供离开保护。
2. 登录：账号登录后进入项目，登录页参考文档的中央白色表单和蓝色按钮；名称统一为“碳建智算平台”，登录页标题居中。
3. 字体：通过 `styles/typography.css` 调整字体、字号与文字对比度；保留 `styles/base.css` 原样、原深蓝配色和布局。
4. 网站链接：按用户标注放在建材搜索框右侧、分类按钮左侧，文字仅为“指导价格”，新窗口打开 `https://www.zjzj.net/`；材料清单右上角原价格来源及季度内容已删除。

`customer.html` 是独立文档，避免平台全局 CSS 影响客户界面。默认项目入口加载此文档；已有因子和版本工具位于项目菜单的独立入口。

本地数据库持久化与 GitHub 代码推送不等于部署到甲方服务器。生产安装与数据库配置参见 `DEPLOYMENT.md`。

## 原源码限制

客户源码包含 `LimitTime = '2026-12-01'` 的使用到期限制；本次未擅自更改。正式使用前需要确认该日期。
